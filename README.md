# Tower Offense — Saltworks Browser Demo

Play at https://imfoot.github.io/Tower_Offense_Demo/.

Build 10 opens the **Saltworks campaign**, starting at **Brinewake Causeway
(01)**. **Maps** offers Brinewake and **Saltworks 09** together; winning
Brinewake offers **Next map** to Saltworks 09. Only completed maps are offered.

| Map | Waves | Exit hearts |
| --- | ---: | ---: |
| Brinewake Causeway (01) | 3 | 24 |
| Saltworks 09 | 5 | 40 |

Both maps offer all six Saltworks classes. Choose one to three before starting
an assault, recruit at most three groups per wave, and use at most two groups
of one class. One living arrival removes one heart. The loadout and evolutions
last for that map; restart to choose again. Victories persist in this browser,
while active battles reset on reload. Previous Saltworks 09 victories are kept.

Brinewake has one automatic road. For Saltworks 09, select each group and
choose 1A or 1B using the road badges or matching buttons below the map.
Arrange queue order with the arrows or drag cards; timing links release groups
together. Click troop cards or built defenses to see details.

The updated Saltworks artwork includes flowing water, waterfalls, pump motion,
directional Pressure Pot fire and articulated troop walks. Brinewake has its
own painting and scenery configuration.

**Maps → Crystal Meadow maps** retains Sunmeadow Trail and Mossgate Reach,
with their reduced browser troop counts, three waves and 20 hearts each.
Both keep the three-class, three-group and two-of-a-kind limits. Mossgate
requires a road choice at both forks. Campaigns retain separate progress.

Use Full screen for a larger view. Desktop mouse and keyboard are the primary
target. Space: launch/pause · N: next batch · F: speed · R: ranges · M: sound.
Tab/Shift+Tab and Enter navigate controls.

This public repository contains only the exported playable demo and browser
runtime. Development source remains separate. Game art is included as part of
the demo; this repository does not grant a separate reuse or redistribution

GitHub Pages serves the main branch root with .nojekyll. No game server or
custom cross-origin isolation headers are required.
